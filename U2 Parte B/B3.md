<p>1. Para una foto con muchos colores y mucha calidad se usa <strong>JPEG (.jpg)</strong>.</p>
<p>2. Para un logo que necesita el fondo transparente usamos <strong>PNG (.png)</strong>.</p>
<p>3. Para un grafico vectorial que no pierda calidad al ampliarlo se usa <strong>SVG (.svg)</strong>.</p>
<p>4. Para una animacion corta tipo meme se usa el tipico <strong>GIF (.gif)</strong>.</p>
<p>5. Para el icono pequeñito de arriba de la pestaña del navegador va <strong>ICO (.ico)</strong>.</p>
